# dice-cli

## Назначение

`dice` бросает кости с заданным числом граней, сохраняет каждый результат в SQLite и показывает статистику выпадения граней.

## Требования

- Python 3.10 или новее.
- Зависимости проекта: Click и SQLAlchemy 2.x.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
```

Также можно запускать команды напрямую через `python dice.py`, не активируя окружение после установки зависимостей.

## Файлы данных и журнал

По умолчанию `stats.db` и `app.log` создаются в текущей рабочей директории. В `stats.db` хранится одна запись на каждую кость. Журнал содержит запуск команд, параметры, результаты, сохранения и ошибки.

Переменная окружения `DICE_DB_URL` позволяет указать другой URL SQLAlchemy. Например, в PowerShell:

```powershell
$env:DICE_DB_URL = "sqlite:///custom-stats.db"
```
